# 📱 Como Obter e Instalar o APK no Celular

---

## 🚀 Método 1: Baixar o APK Direto pelo GitHub Actions (Automático)

1. No seu repositório no **GitHub**, clique na aba **"Actions"** (no topo).
2. Selecione o workflow **"Gerar APK Android - GKD Controle Diário"** no menu à esquerda.
3. Se quiser rodar manualmente, clique em **"Run workflow"** ➔ **"Run workflow"**.
4. Quando a execução terminar (ícone verde de check ✅), clique nela.
5. Na seção **Artifacts** (no final da página), baixe o arquivo **`GKD_Controle_Diario_APK`**.
6. Transfira ou abra no seu smartphone Android e clique para **Instalar o APK**.

---

## ⚡ Método 2: Instalação Instantânea PWA (Sem precisar de APK)

O aplicativo é um **Progressive Web App (PWA)** completo:
1. Abra o link do aplicativo no **Google Chrome** do seu celular Android.
2. Toque no menu de **3 pontinhos** do Chrome (canto superior direito).
3. Toque em **"Instalar aplicativo"** ou **"Adicionar à tela inicial"**.
4. O app será instalado instantaneamente com o ícone oficial do **GKD Mobility**, funcionando em tela cheia e offline.

---

## 🌐 Método 3: Gerar APK com WebIntoApp (Via ZIP)

1. No aplicativo, abra a Central de Backup e baixe o arquivo **`controle_diario_offline.zip`**.
2. Acesse o site gratuito [WebIntoApp](https://www.webintoapp.com/).
3. Escolha **"Upload Local HTML / ZIP"**.
4. Envie o arquivo `controle_diario_offline.zip`.
5. Defina o nome: **GKD Controle Diário** e selecione o ícone `icon2.png`.
6. Clique em **Generate APK** e faça o download do instalador `.apk`.
