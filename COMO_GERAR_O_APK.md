# Como Gerar o APK Offline (WebIntoApp)

1. Baixe o arquivo `controle_diario_offline.zip` pelo botão **"Baixar ZIP APK"** no topo da tela do aplicativo.
2. Acesse [WebIntoApp](https://www.webintoapp.com/).
3. Selecione a opção **"Upload Local HTML / ZIP"** (não use URL).
4. Faça o upload do arquivo `controle_diario_offline.zip`.
5. Preencha o nome do App: **Controle Diário - GKD Mobility**.
6. Clique em **Generate APK** e baixe o aplicativo no seu smartphone.
7. O aplicativo rodará 100% offline salvando todos os dados no armazenamento local do aparelho.
